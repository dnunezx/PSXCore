# POPS/PSXCore graphics investigation

**Correction target: POPS texture-window code in PS2 RAM.** PSXCore installs it as [shared core behavior](../../RUNTIME-CORRECTIONS.md), independently of game profiles. Never troubleshoot or modify PCSX2. Historical host tracing code and its parser/runner have been removed. The observations below record prior evidence, not instructions to reproduce a modified host.

## Texture-window experiment

On 2026-10-05, a privately supplied Doom scene exhibited sky smearing while turning. The [reverse-engineered sky renderer](https://raw.githubusercontent.com/Erick194/PSXDOOM-RE/master/PSXDOOM/r_phase2.c) draws a scrolling textured sprite. In the recorded scene, the decoded sky source was visually intact and all 65,536 bytes of its cached page matched the corresponding VRAM source. The traced GS sprite had horizontal clamp (WMS=1) with U ranging from 121.4375 to 376.4375 on a 256-texel texture. Clamping coordinates beyond 255 repeats the edge column rather than wrapping.

The pinned native texture-window handler selects mode 1 for an axis with zero texture-window mask and mode 3 for a masked axis. The one-word experiment cataloged in `patches/pops-texture-window-wrap.json` changes the unmasked selection to mode 0 and retains mode 3 for masked axes. After loading the verified experimental state copy, 207 matching sprite batches recorded horizontal repeat and the preserved game visibly rendered the sky correctly. CPU rate/skip remained zero; native runtime and game files were unchanged. Scene/view changes prevent attributing any FPS difference to this graphics correction. No performance repair is claimed.

`state_patch.py` supports guarded, reproducible experiments without changing the input state or the supplied runtime file. It requires an exact input-state SHA-256, a new output filename, 32 MiB EE RAM and a matching word at an aligned physical RAM address. It verifies the rebuilt archive, exact changed RAM, and unchanged sizes/CRCs of every other member. Use an independently installed 7-Zip executable for PCSX2 Zstandard ZIP members. Verify the separately supplied runtime fingerprint and target semantics first; a matching word alone does not establish runtime identity.

```text
python state_patch.py --sevenzip PATH_TO_7Z --state PRIVATE_STATE --sha256 STATE_SHA256 --output NEW_PRIVATE_STATE --address PHYSICAL_ADDRESS --expected ORIGINAL_WORD --replacement EXPERIMENT_WORD
```

Keep the original state for rollback. The state-copy experiment alone installs no boot-time fix. Catalog revision 2 originally selected wrapping through the exact Doom profile, with a cold boot confirming the instruction correction. Revision 3 moves it into `src/runtime_corrections.c`, removes the optional wrapping manifest/bit, and installs it for all games and bootstrap modes on the supported runtime. Default-mode cold boot (optional mask 0) and unidentified-game Custom cold boot (mask 3) both selected baseline, logged core revision 1, and exposed corrected instruction `0x240f0000` through read-only PINE without loading any state. Expected original word is `0x240f0001` at `0x0021d6a4`. EE rate/skip stayed zero. Supplied POPS and PCSX2 executable hashes were unchanged. The host retains historical modifications; stock-host, broader games and physical-console behavior remain unverified. The FPS issue remains open. No game, native executable, state, texture or BIOS payload is included.
